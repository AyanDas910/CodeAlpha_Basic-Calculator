NOVA / CALC — Smart Calculator

How to run:
1. Extract the ZIP file.
2. Open index.html in a modern browser.

Features:
- Addition, subtraction, multiplication, division
- Clear, backspace, decimal, sign toggle, percent
- Square root, square, reciprocal, π
- Memory controls (MC, MR, M+, M−, MS)
- Calculation history (click a history item to reuse its result)
- Keyboard support: digits, + - * /, Enter, Backspace, Esc, %, decimal
- Dark/light theme toggle and responsive layout

This is a front-end demo; calculations run locally in your browser.
